# Block Blast — «Удобные блоки» 🧱

Сайт-игра в жанре Block Blast (поле 8×8, очистка линий) с ключевой фишкой:
**умный генератор фигур** подбирает наиболее «удобные» блоки под текущую
ситуацию на поле.

## Как запустить
Просто откройте `index.html` в браузере, либо поднимите локальный сервер:
```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Правила
- Перетаскивайте фигуры из нижнего дока на поле 8×8 (мышь или палец).
- Полностью заполненные строки и столбцы взрываются («бласт»).
- После использования трёх фигур выдаётся новая волна.
- Игра заканчивается, когда ни одну из оставшихся фигур некуда поставить.
- Комбо за несколько линий подряд и серии чистых ходов дают бонусные очки.
- Рекорд сохраняется в localStorage.

## Режим «Умные блоки» (главная фишка)
Каждая кандидатура в фигуру оценивается эвристикой полезности для текущего поля:
1. **Очистка линий** — может ли фигура завершить строку/столбец (главный вес).
2. **Близость к завершению** — «почти готовые» линии (осталось ≤2 клетки).
3. **Компактность** — штраф за создание изолированных «карманов»-дыр.
4. **Выживаемость** — остаётся ли место (квадраты 2×2) для будущих фигур.

Из N случайных кандидатов выбирается лучший. Уровень комфорта:
- **Легко** — 12 кандидатов, жадность 97%: почти всегда идеально удобные фигуры.
- **Средне** — 6 кандидатов, жадность 80%: удобно, но без гарантий.
- **Хардкор** — 3 кандидата, жадность 55%: близко к классической случайности.

Тумблер «Умные блоки» полностью отключает подбор (обычный случайный режим,
но с проверкой, что фигура куда-то влезает).
